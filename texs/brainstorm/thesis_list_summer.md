# Список тезисов летнего отчёта (черновик v3)

Принцип: по умолчанию ПУЛ held-out {2}+{5}; раздельные фолды — только где разброс сам и есть доказательство (T2).

## I. Методология (главный вклад)
- **M1 (мотивация / related work).** Оригинальный DeepPeptide: 5-фолд nested CV, гомология ≤30%, баланс по мотивам. Честен для гиперпараметров, НО архитектура выбиралась на тех же фолдах, что и репортятся (нет holdout под выбор архитектуры); деплой-ансамбль из 20 моделей не оценивался на честно отложенных. → headline слегка оптимистичен.
- **M2.** Пересобрали 2026 → чистый 7-фолд (гомология+мотивы, рецепт статьи воспроизведён) с явными ролями train / dev / model-select / [sealed].
- **M3.** Нашли+починили баг матчера ±3 (variable shadowing). Corrected сдвигает числа равномерно ~+0.01–0.015, РАНГИ не меняет → баг не искажал выводы (само по себе подтверждение). Репортим corrected.
- **M4 (ПРОБЛЕМА — показать, не «решить»).** Разбиение балансировало мотивы, НЕ длину/организм → фолды неэквивалентны по композиции. Следствие: **результаты по фолдам сильно рознятся** — модели решафлятся (zeroctrl↔3Di меняются местами), венозный Cyriopagopus даёт −0.22 на одном фолде. Это эффект КОМПОЗИЦИИ фолда, не модели. Полный фикс — nested-CV (каждый белок тестируется один раз, виды взвешены по истинной частоте; micro-avg всех тест-предсказаний); не делаем по стоимости → ограничения.
- **M5 (компромисс).** Сравниваем на ПУЛЕ held-out {2}+{5}: комплементарные перекосы длины гасятся (pep 0.41/0.28→0.17, L1≈0.10), n≈2300. Sealed-от-выбора-архитектуры фолда нет (как и в оригинале) → честно как ограничение. «Где что лучше» — композиционно-инвариантный stratified-анализ.

## II. КЛЮЧЕВОЙ ТЕЗИС: данные — главный рычаг
- **T0.** Самый сильный практический драйвер качества — ОБЪЁМ и покрытие обучающих данных, а не архитектура. Последовательности, НЕпохожие на train (гомологически далёкие — а в нашем сплите held-out именно такие, ≤30% идентичности), предсказываются плохо → больше данных = больше покрытие пространства → выше качество.
  - Показано на 2022 (scaling по доле train); кривая не выходила на плато → модель data-limited.
  - **НУЖНО воспроизвести на чистом протоколе 2026:** train на долях train-фолдов **40/55/70/85/100%** (низ 10–40% вырожден — модель не учится), eval на пуле {2,5}, corrected ±3. Модели — **baseline + 6B+proj + 6B+3Di** (весь топ-тир, без коронации одной). Если 40→100 ещё растёт → data-limited. ~день GPU, эмбеддинги переиспользуем. _[новый прогон]_

## III. Архитектура: взаимодействие «голова × эмбеддинги» (3 тезиса + синтез)
- **T1.** Голова (boundary/проектор) на БОГАТЫХ эмбеддингах (ESM-C 6B) → +0.05–0.07 F1, оба фолда. **Единственный безусловный рычаг ИЗ ПРОВЕРЕННЫХ.** Внутрь T1:
  - КАК: голова заостряет границы — при сжатии окна матча ±3→±0 retention растёт (baseline 0.55 → +head 0.70 → +3Di 0.72); baseline теряет 45% F1 при точном совпадении, голова ~30%.
  - ГДЕ: выигрыш — recall на ДЛИННЫХ пептидах + precision на КОРОТКИХ предсказаниях.
- **T2.** Богатые эмбеддинги САМИ по себе — слабый/НЕустойчивый прирост: 6B vs ESM2 ≈ +0.03 на пуле, но знак скачет по фолдам (+0.074 / −0.011); 6B vs 600M ≈ 0. _[раздельные фолды — разворот = доказательство]_
- **T3.** Голова на СЛАБЫХ эмбеддингах (ESM2) → ~0. Чистый замер: новый ран `2026_esm2_boundary` (boundary, λ=0, без bond — зеркало `esmc6b_boundary`) vs baseline; ранее на bond-загрязнённом было +0.019/+0.002. _[ран запущен 2026-06-20]_
- **Синтез T1–T3.** Рычаг = ВЗАИМОДЕЙСТВИЕ «голова × богатые эмбеддинги»; ни то, ни другое соло. Ответ «почему раскрылось на ESM-C, а не на ESM2».

## IV. Доп. каналы (размены, не рычаги)
- **T4 (3Di).** Размен: пропептидам +, пептидам − (в основном recall, урон на длинных). Net на пуле ≈ ничья.
- **T5 (сжатие).** seq 2560→256 стоит ~0 F1 (парная Δ≈0) → модель в 16× меньше (0.87M vs 13.6M) бесплатно. **Обоснование выбора 256: доказано-lossless, не произвольно.**
- **T6 (bond).** Не чистый размен, нейтрально-в-минус (теряет recall пептидов).
- **Сквозное.** 3Di и bond — одна сигнатура (к пропептидам ценой recall пептидов). Безусловный рычаг один — голова на богатых.
- **О «победителе» (важно для защиты): НЕ коронуем одну модель.** Топ-тир = `6B+proj (3Di=0)` 0.694 ≈ `6B+3Di` 0.692 (в пределах шума). proj = «полная архитектура без структуры» (gated-проектор+boundary; +0.03 recall над plain — это сам проектор); 3Di = «+структурный канал» = размен P↔R (после длины 30 проигрывает по F1/recall). Репортим оба как топ-тир, не выбираем «winner».

## V. Прочие проведённые эксперименты (честно; не замалчиваем)
Метрики ЧЕСТНО перепроверены — есть большая сводная таблица (corrected ±3, all/pep/propep). Каверзность только в МЕТОДЕ: старый 2022-й 5-фолд + **выбор модели по val** (тот же фолд, что под эпоху), модели скачут между фолдами. → выводы по ним требуют перепроверки на чистом протоколе.

- Aho/Ахо-Корасик: emission/state/CRF-bias/early fusion — разведочно.
- AFTK структурные фичи (single/pair/lddt) — разведочно.

## VI. Робастность по новизне (узко)
- **T7.** Recall НЕ падает на post-2022 семействах внутри held-out (≈0.76) — наблюдение о робастности, БЕЗ заявки на кросс-датасетную генерализацию (модель училась на 2026). Честный тест 2022→2026 — future work.

## VII. Ограничения (related work)
- Нет полного nested-CV — единственный полный фикс M4 и путь к одному чистому глобальному числу с честным выбором архитектуры (отложено по стоимости).
- Нет sealed-от-выбора-архитектуры фолда (следствие пулинга).
- CI только protein-bootstrap → консервативно.
- Не тестировали на чистом протоколе: Ankh, дообучение pLM / contrastive, трансформер-голову → T1 «единственный из проверенных».
